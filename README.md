Coffee Spot ☕

About the Project

Coffee Spot is a coffee shop website designed to provide visitors with information about my coffee shop, menu, and services.

Features

Attractive homepage
Coffee shop logo and hero banner
Navigation links
Coffee menu
User-friendly design

Technologies Used

HTML
CSS

Purpose

This project was created as a practical exercise to develop my front-end web development skills. It focuses on designing and building the visual interface of a coffee shop website using HTML and CSS. The project helped me practice creating web pages, styling website elements, and developing a user-friendly design. It is a front-end project and does not yet include back-end functionality.
